# Semana 5 — Ejercicios de redes neuronales

Esta carpeta contiene notebooks de aprendizaje automático y redes neuronales.

## Notebooks

1. Preprocesamiento y exploración de datos.
2. Perceptrón y perceptrón multicapa (MLP).
3. Redes convolucionales (CNN): clasificación de imágenes y detección de objetos.
4. Redes recurrentes (RNN): análisis de sentimientos, series temporales, descripción de imágenes y ejercicio de triaje.
5. Entrenamiento, ajuste de hiperparámetros, evaluación y despliegue de modelos.

## Ejecución

Los archivos son notebooks de Jupyter. Puedes abrirlos con Jupyter Notebook, VS Code o subirlos a Google Colab. Revisa las celdas de instalación y los recursos requeridos antes de ejecutar cada ejercicio.
